# Preprocessed EEG Data

The preprocessed EEG datasets for 33 participants are hosted on Zenodo: [Download the dataset](https://doi.org/10.5281/zenodo.23764504).

Download the dataset, then place each participant's matching `.set` and `.fdt` files in this directory before running the EEG analysis scripts. Keep each pair together. The `.set` files can be opened in MATLAB using EEGLAB.
